1. ካፓሲተር (Capacitor)

ካፓሲተር የኤሌክትሪክ ኃይልን በኤሌክትሮስታቲክ መስክ (Electrostatic field) መልክ አከማችቶ የሚይዝ እና እንደ አስፈላጊነቱ ፈጥኖ የሚለቅ የኤሌክትሮኒክስ መለኪያ ነው። በሰርኪዩት ውስጥ ቮልቴጅን ለማለስለስ (Filtering) እና ጫጫታን (Noise) ለማስወገድ ያገለግላል።

ዋና ዋና አይነቶች፦

  • Electrolytic Capacitor: አወንታዊ (+) እና አሉታዊ (-) ፖላሪቲ ያለው ሲሆን በፓወር ሰፕላይ ሰርኪዩቶች ላይ ይሰራል፤ ሲሰካ አቅጣጫ መሳሳት የለበትም።
  • Ceramic Capacitor: ፖላሪቲ የሌለው፣ አነስተኛ መጠን ያለው እና ለከፍተኛ ፍሪኩዌንሲ ፍልሰት የሚያገለግል ነው።

በመልቲሜትር መለኪያ መንገድ፦

  • መልቲሜትሩን ወደ Capacitance (Farad/F) ሞድ አስተካክል።
  • ከመለካትህ በፊት የካፓሲተሩን ሁለት እግሮች በስክሪው ድራይቨር በማጫረስ (Discharge) የያዘውን ኤሌክትሪክ አውጣ።
  • የመልቲሜትሩን ፕሮቦች ከእግሮቹ ጋር አገናኝ፤ በስክሪኑ ላይ የሚመጣውን ዋጋ (uF/nF) አካሉ ላይ ከተጻፈው ጋር አወዳድር።

1. Capacitor

A capacitor is a passive electronic component that stores electrical energy in an electrostatic field and releases it when needed. It is primarily used for filtering voltage fluctuations and removing noise in circuits.

Main Types:

  • Electrolytic Capacitor: Polarized (+ and -), commonly used in power supply circuits. Polarity must be strictly observed during installation.
  • Ceramic Capacitor: Non-polarized, compact, and ideal for high-frequency filtering applications.

How to Test with a Multimeter:

  • Set the multimeter to Capacitance (Farad/F) mode.
  • Discharge the capacitor completely by shorting its leads prior to testing.
  • Connect the multimeter probes to the leads and compare the measured value (uF/nF) with the rating printed on the body.

2. ዳዮድ (Diode)

ዳዮድ የኤሌክትሪክ ፍሰት (Current) ወደ አንድ አቅጣጫ ብቻ እንዲያልፍ የሚፈቅድ እና ወደ ተቃራኒው አቅጣጫ የሚመጣውን የሚግት ኮምፖነንት ነው። ኤሲ (AC) ቮልቴጅን ወደ ዲሲ (DC) ለመቀየር (Rectification) ያገለግላል።

ዋና ዋና አይነቶች፦

  • Rectifier Diode (1N4007): ኤሲ ቮልቴጅን ወደ ዲሲ ለመቀየር የሚያገለግል።
  • Zener Diode: ቮልቴጅን በተወሰነ መጠን ረግቶ እንዲቆይ (Voltage Regulation) የሚያደርግ።
  • LED (Light Emitting Diode): ኤሌክትሪክ ሲያልፍበት ብርሃን የሚሰጥ።

በመልቲሜትር መለኪያ መንገድ፦

  • መልቲሜትሩን ወደ Diode Mode (▶|) ቀይር።
  • ቀዩን ፕሮብ ከአኖድ (+)፣ ጥቁሩን ከካቶድ (-) ጋር አያይዝ፤ በስክሪኑ ላይ ከ0.5V - 0.7V ያሳያል (Forward Bias)።
  • ፕሮቦቹን ስትገለብጣቸው ምንም አይነት ንባብ (OL) ማሳየት አለበት (Reverse Bias)። በሁለቱም በኩል ድምፅ (Beep) ካሰማ ዳዮዱ ተቃጥሏል።

2. Diode

A diode is a semiconductor component that allows current to flow in one direction only while blocking it in the reverse direction. It is essential for converting AC voltage to DC (Rectification).

Main Types:

  • Rectifier Diode (e.g., 1N4007): Standard diode used for AC to DC conversion.
  • Zener Diode: Designed to maintain a stable reference voltage in circuits.
  • LED (Light Emitting Diode): Emits light when electric current passes through it.

How to Test with a Multimeter:

  • Set the multimeter to Diode Mode (▶|).
  • Connect the red probe to the Anode (+) and black probe to the Cathode (-); it should read around 0.5V - 0.7V (Forward Bias).
  • Reverse the probes; the screen should display "OL" (Reverse Bias). If it beeps in both directions, the diode is shorted.

3. ሪዚስተር (Resistor)

ሪዚስተር በሰርኪዩት ውስጥ የሚያልፈውን የኤሌክትሪክ ፍሰት (Current) ለመገደብ እና ቮልቴጅን ለመክፈል (Voltage Divider) የሚያገለግል ተገብሮ (Passive) ኮምፖነንት ነው።

አነባበብ እና መለኪያ፦

  • የቀለም ኮድ (Color Code): አካሉ ላይ ባሉት ቀለማት አማካኝነት የኦህም (Ω) መጠኑ ይነበባል።
  • በመልቲሜትር፦ መልቲሜትሩን ወደ Ohms (Ω) ቀይረህ የሪዚስተሩን ሁለት ጫፎች ለካ። የሚመጣው ንባብ ከቀለሙ ኮድ ዋጋ ጋር ተመሳሳይ መሆን አለበት።

3. Resistor

A resistor is a passive electrical component that limits the flow of electric current and lowers voltage levels within a circuit.

Reading & Testing:

  • Color Code: Resistance values are represented by colored bands printed on the component body.
  • Multimeter Testing: Set the multimeter to Ohms (Ω) mode and measure across both leads. The display should match the rated color code resistance.

4. ሞስፌት (MOSFET)

ሞስፌት (Metal-Oxide-Semiconductor Field-Effect Transistor) በከፍተኛ ፍጥነት የኤሌክትሪክ ፍሰትን ለመቆጣጠር፣ እንደ ስዊች (Switch) እና አምፕሊፋየር ሆኖ የሚያገለግል ወሳኝ ትራንዚስተር ነው።

ሶስቱ እግሮች (Terminals)፦

  • Gate (G): ስዊቹን የመክፈቻ/መዝጊያ መቆጣጠሪያ።
  • Drain (D): ኤሌክትሪክ የሚገባበት/ሚወጣበት ዋና መስመር።
  • Source (S): ኤሌክትሪክ የሚወጣበት/ሚገባበት መስመር።

በመልቲሜትር መለኪያ መንገድ፦

  • መልቲሜትሩን ወደ Diode mode አድርገህ በDrain እና Source መካከል ያለውን የውስጥ ዳዮድ (Body Diode) ለካ፤ በይበልጥ ከ0.4V - 0.6V ያሳያል።
  • በGate እና Drain ወይም በGate እና Source መካከል መለካት የለበትም (OL ማሳየት አለበት)።

4. MOSFET

A MOSFET is a semiconductor device widely used for switching and amplifying electronic signals in modern electronics circuits.

Three Main Terminals:

  • Gate (G): Controls the opening and closing of the channel.
  • Drain (D): Main current entry/exit terminal.
  • Source (S): Connected to ground or supply reference.

How to Test with a Multimeter:

  • Set multimeter to Diode mode and check between Drain and Source to verify the internal body diode (typically reads 0.4V - 0.6V).
  • Ensure there is no continuity (OL) between Gate-Drain or Gate-Source terminals.
